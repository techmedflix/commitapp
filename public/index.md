# Commit

> Everything you owe. Everything owed to you.

Commit is a web app for team commitments. It is a single system of record for work between a **Creator** (who asks) and a **Doer** (who owns the work).

This Markdown page is the LLM-friendly homepage. The human app is at `/` (Google sign-in, `@medflix.app` only). Canonical assistant files: `/llms.txt` and `/llms-full.txt`.

## Two inboxes

- **My Work** — what I need to do (Doer view)
- **Waiting For** — what I am waiting on others to do (Creator view)

## Workflow

1. Create (assign to a Doer)
2. Acknowledge and accept (Doer sets their own ETA)
3. Start working
4. Blocked / nudge if needed
5. Complete

Commit is not Git, GitHub, or source control.

## Access

Google OAuth, restricted to `@medflix.app` accounts. Join an organization with an invite link (`/?invite=CODE`) or create one after sign-in.
