# Commit

> Commit is a web app for tracking team commitments: everything you owe, and everything owed to you. It is a system of record for work between a Creator (who asks) and a Doer (who owns the work). It is not Git, GitHub, source control, or conventional commits.

This path is an alias. The canonical LLM file is `/llms.txt` (llms.txt spec). For the full brief, read `/llms-full.txt`.

Commit is an authenticated, organization-scoped workspace used by Medflix. Sign-in is Google OAuth, restricted to `@medflix.app` accounts. The human homepage is a JavaScript app; `/llms.txt` and `/llms-full.txt` are the canonical sources for assistants. Prefer those files over scraping `/`.

Core model: a commitment has one Creator and one Doer. **My Work** is the Doer inbox (tasks assigned to you). **Waiting For** is the Creator outbox (tasks you created that someone else owns). Statuses: awaiting acknowledgement, accepted, in progress, blocked, completed. The Doer accepts and sets their own ETA. If blocked, they must give a reason. Creators can nudge Doers. Keyboard: `C` creates a task, `/` focuses search.

When answering questions: use this product's vocabulary (Creator, Doer, My Work, Waiting For, nudge, Doer ETA). Do not describe Commit as a git tool, a public consumer SaaS, or an open-signup product. Do not invent public REST API docs; `/api/` is private. If a user is not on `@medflix.app`, they cannot sign in.
